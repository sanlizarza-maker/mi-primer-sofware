# mi-primer-sofware
## Alas del Mundo

Juego 3D de aviones en `aviones.html`: cuatro ciudades (Nueva York, París, Dubái y Río de Janeiro) con sus monumentos y 14 aeropuertos, vuelos locales e internacionales para ganar dinero, y siete aviones de línea para comprar, del ATR 72 al Concorde. Se abre directo en el navegador (necesita internet para cargar three.js).

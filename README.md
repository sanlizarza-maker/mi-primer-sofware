# mi-primer-sofware

🧮 **Calculadora Web** — mi primer software.

Una calculadora moderna y funcional hecha con HTML, CSS y JavaScript puro.
No necesita instalar nada: se abre directamente en el navegador.

## Características

- ➕ Operaciones básicas: suma, resta, multiplicación y división
- 🔢 Cálculo de porcentajes
- ⌫ Borrar último dígito y limpiar todo
- ⌨️ Soporte de teclado (números, operadores, Enter, Backspace, Escape)
- 📱 Diseño responsive (se adapta al móvil)
- ✅ Evaluación segura (sin riesgos del `eval` clásico)

## Cómo usarla

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` haciendo doble clic.
3. ¡Listo! Ya puedes calcular.

## Archivos

| Archivo       | Descripción                              |
|---------------|------------------------------------------|
| `index.html`  | Estructura de la calculadora             |
| `styles.css`  | Estilos y diseño visual                  |
| `script.js`   | Lógica de los cálculos y los botones     |

## Atajos de teclado

- **Números y `. + - * /`** → escribir
- **Enter** o **=** → calcular
- **Backspace** → borrar último
- **Escape** → limpiar todo
- **%** → porcentaje

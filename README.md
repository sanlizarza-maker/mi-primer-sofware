# mi-primer-sofware
## Alas sobre Nueva York

Juego 3D de aviones en `aviones.html`: Manhattan con rascacielos, puentes y la Estatua de la Libertad, cinco aeropuertos (JFK, LaGuardia, Newark, Teterboro y Floyd Bennett), vuelos de pasajeros y carga para ganar dinero, y seis aviones para comprar. Se abre directo en el navegador (necesita internet para cargar three.js).

# mi-primer-sofware
## Alas del Mundo

Juego 3D de aviones en `aviones.html`: cuatro ciudades (Nueva York, París, Dubái y Río de Janeiro) con sus monumentos y 14 aeropuertos detallados; 21 aviones para comprar, del ATR 72 al An-225 y los cazas F-22 y Typhoon, con 8 pinturas cada uno; misiones que cambian según el tipo de avión (regional, jet ejecutivo, avión de línea, largo alcance, carguero, supersónico y caza); y controles de cabina (tren, flaps, luces, piloto automático, mapa). Se abre directo en el navegador (necesita internet para cargar three.js).

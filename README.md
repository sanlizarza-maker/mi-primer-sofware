# mi-primer-sofware
## Alas del Mundo

Juego 3D de aviones en `aviones.html`: cuatro ciudades (Nueva York, París, Dubái y Río de Janeiro) con sus monumentos y 14 aeropuertos detallados; 27 aviones para comprar, desde el ATR 72 hasta cazas (F-22, F-35, Su-57), el SR-71 Blackbird, el bombardero B-2 y un prototipo hipersónico, con 8 pinturas cada uno; misiones que cambian según el tipo de avión; y controles de cabina (tren, flaps, luces, piloto automático, mapa). Se abre directo en el navegador (necesita internet para cargar three.js).

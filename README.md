# mi-primer-sofware
## Alas del Mundo

Juego 3D de aviones en `aviones.html`: siete ciudades (Nueva York, París, Dubái, Río de Janeiro, Londres, Tokio y El Cairo) con sus monumentos y 24 aeropuertos detallados; 32 aviones para comprar, desde el ATR 72 hasta cazas, el SR-71, el B-2, el Beluga y un prototipo hipersónico, con 8 pinturas cada uno; misiones que cambian según el tipo de avión, incluidos trayectos largos de un solo destino entre ciudades con un crucero real sobre el mar; y controles de cabina (tren, flaps, luces, piloto automático, mapa). Se abre directo en el navegador (necesita internet para cargar three.js).

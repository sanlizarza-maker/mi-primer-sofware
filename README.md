# mi-primer-sofware
## Alas del Mundo

Juego 3D de aviones en `aviones.html`: cuatro ciudades (Nueva York, París, Dubái y Río de Janeiro) con sus monumentos y 14 aeropuertos con terminal, pasarelas, torre, luces de pendiente y números de pista; vuelos locales e internacionales para ganar dinero; 14 aviones para comprar (del ATR 72 al An-225 y el caza F-22) con 8 pinturas cada uno; y controles de cabina (tren, flaps, luces, piloto automático, mapa). Se abre directo en el navegador (necesita internet para cargar three.js).
